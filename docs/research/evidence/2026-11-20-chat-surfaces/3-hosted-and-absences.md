# Hosted chat surfaces for a remote MCP server, client-portal pattern, and absence checks

Evidence file, gathered 2026-11-20. Scope: which hosted or commercial chat surfaces staff and an agency's clients could use to reach a stateless Streamable HTTP MCP server that is an OAuth 2.1 resource server (RFC 9728, tokens from an OIDC IdP such as Zitadel), confirms through form-mode elicitation (2026-07-28 multi-round-trip style) and ships MCP Apps (`ui://`) views. Every claim carries the URL it came from. "Not documented" means the cited primary page was read and is silent; it does not mean the feature is absent.

## Summary

1. **Only ChatGPT documents 2026-07-28 form elicitation for remote servers.** OpenAI's extension spec says OpenAI-registered servers "require MCP `2026-07-28` or later with multi-round-trip requests (MRTR) for form elicitation", and needs an `openai/elicitation` extension capability on top of core `elicitation.form` ([openai/mcp-extensions spec](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md#openai-form-elicitation)). Microsoft Copilot Cowork supports core form-mode elicitation ([Learn](https://learn.microsoft.com/en-us/copilot/cowork/cowork-elicitation-forms)). On claude.ai elicitation is an open feature request ([anthropics/claude-ai-mcp#153](https://github.com/anthropics/claude-ai-mcp/issues/153), open, last comment 2026-10-07). No other hosted surface documents it.
2. **MCP Apps rendering**: per the official matrix, these clients render MCP Apps: Claude (web), Claude Desktop, VS Code GitHub Copilot, Microsoft 365 Copilot, ChatGPT, Cursor and Glean ([client matrix source](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/docs/extensions/client-matrix.mdx)). The rendered page at https://modelcontextprotocol.io/extensions/client-matrix draws the check marks as icons, so a text fetch shows empty cells; the MDX source carries `<CHECK />`. Gemini Enterprise ([Google Cloud blog](https://cloud.google.com/blog/topics/developers-practitioners/devs-guide-to-mcp-apps-in-gemini)) and the Slackbot MCP client ([Slack docs](https://docs.slack.dev/ai/slackbot-mcp-client/)) also document MCP Apps, but neither is in the matrix. Mistral Le Chat, Perplexity, Microsoft Teams channel agents, Open WebUI and LibreChat are not in the matrix.
3. **OAuth registration differs per host.** CIMD + DCR + a static client: ChatGPT and Claude. DCR + a static client, no CIMD: Copilot Studio, M365 declarative agents, Glean and Perplexity. Static client only: Gemini Enterprise. Mistral documents DCR only. Slack offers DCR, manual OAuth (it publishes its own CIMD document) and a signed `slack_identity_auth`.
4. **External clients (guests) are the weak point everywhere.** Claude Tag (Claude in Slack) is the only surface found that documents a mode built for guests: "Channel only" is described as being for "a channel shared with contractors, clients, or agency partners". Guests cannot approve tool calls in that mode ([Claude docs](https://claude.com/docs/claude-tag/admins/restrict-access.md)). M365 agents refuse to answer when guests are in a chat or channel ([Microsoft Support](https://support.microsoft.com/en-US/sharepoint/copilot-in-sharepoint/share-an-agent-from-sharepoint-in-teams)). ChatGPT Business shared links do not open for people outside the workspace (search snippet of [OpenAI Help 8798634](https://help.openai.com/en/articles/8798634-chatgpt-shared-links-faq-business-version); the page itself could not be fetched).
5. **EU data residency**: OpenAI offers EU at-rest residency for ChatGPT Enterprise and Edu, plus EU inference residency ([OpenAI](https://openai.com/index/introducing-data-residency-in-europe/), [Help 9903489](https://help.openai.com/en/articles/9903489-data-residency-and-regional-data-processing-for-chatgpt)). Microsoft offers the EU Data Boundary with a Flex Routing exception. Mistral is EU-hosted by default and can be self-hosted. Anthropic says Claude data "is stored in the US" ([Anthropic privacy](https://privacy.claude.com/en/articles/7996890-where-is-my-data-stored)). Gemini Enterprise has an `eu` multi-region.
6. **Client-portal pattern**: the parts exist, but nobody sells the whole thing. Customers can file requests through Linear Asks in shared Slack channels. Jira Service Management portals have a Rovo "Raise a request" agent, and Intercom Fin acts over MCP. Cursor and Claude Tag turn a Slack bug report into a PR. No product was found where an outside client talks to an agent that files dev work and then follows it to a reviewed PR over MCP.
7. **Absence check: zero third-party mentions of Unfold (unfold-hq, unfoldhq.dev) or Ploeg (ploeg-hq)** in the official MCP Registry, PulseMCP, mcp.so, Glama, the Open WebUI and LibreChat repositories, or the open web. The only GitHub hits are the projects' own repositories and one downstream deployment repository of the maintainer. The name "Unfold" is already taken in the registry and on Glama by unrelated servers.

## Sources per surface

### ChatGPT (OpenAI)

- Adding a server: "Go to ChatGPT Plugins → Add custom MCP server … Supported MCP protocols: SSE and streaming HTTP. Authentication options include **OAuth**, **No authentication**, and **OAuth or no authentication**." It continues: "For OAuth, if static credentials are provided, then they will be used. Otherwise, ChatGPT can use Client ID Metadata Documents when the authorization server advertises support … CIMD supports public-client token exchange (`none`) and signed client assertion token exchange (`private_key_jwt`). ChatGPT can also use DCR when configured." https://developers.openai.com/api/docs/guides/custom-mcp-server
- Write actions: "Write actions by default require confirmation … Tools without this [`readOnlyHint`] are treated as write actions." The same page says "Workspace permissions and security restrictions, including Lockdown, apply." https://developers.openai.com/api/docs/guides/custom-mcp-server
- Auth requirements: "Use Client ID Metadata Documents (CIMD) as the preferred client registration method." The host must serve protected resource metadata and echo `resource` through the whole flow. ChatGPT uses RFC 9207 issuer identification. "ChatGPT runs DCR once per MCP server connection, then keeps and reuses the registered OAuth client." Enterprise workspaces can verify email domains to limit account linking. https://developers.openai.com/apps-sdk/build/auth (also https://developers.openai.com/plugins/build/auth.md)
- Elicitation: "Use MCP elicitation when the server needs structured information that was not provided in the original tool call … Do not use it to collect secrets." https://developers.openai.com/plugins/build/mcp-server.md
- 2026-07-28 form elicitation: "OpenAI-registered MCP servers require MCP `2026-07-28` or later with multi-round-trip requests (MRTR) for form elicitation. Direct MCP connections still support legacy forms." "MCP Servers MUST require both `elicitation.form: {}` and `extensions["openai/elicitation"].form: {}`," and the real schema goes in `_meta["openai/elicitation"]["requestedSchema"]`. https://github.com/openai/mcp-extensions/blob/main/docs/spec.md#openai-form-elicitation. Implication for Unfold: a core-only `elicitation/create` InputRequired without the OpenAI extension "will be reported as unsupported". (Inference from the quoted MUSTs; not tested.)
- MCP Apps: "ChatGPT implements the open MCP Apps standard." ChatGPT extensions add sidebar apps, conversation panels, plugin settings and extended forms. https://developers.openai.com/plugins/build/chatgpt-ui.md, https://developers.openai.com/plugins/build/extensions.md
- Plans and admin: the help center article could not be fetched (HTTP 403 to automated fetch), so these come from search snippets of https://help.openai.com/en/articles/12584461-developer-mode-and-full-mcp-connectors-in-chatgpt. Developer mode is available to "Pro, Plus, Business, Enterprise and Education accounts on the web". On Business, "Only Admins and Owners can publish apps" (Workspace settings → Apps → Drafts → Publish), and admins cannot turn on developer mode for members. On Enterprise and Edu, admins "use RBAC to provide developer mode access to select individuals, and then choose who can access each vetted app". **Not verified on the page.** The pricing page lists "Developer mode (beta)" for Plus and Pro and none for Free or Go. It says "Business plans are available starting at 2 users" and shows no prices. https://chatgpt.com/pricing
- EU: "New ChatGPT workspaces can be set up with data residency in Europe" for Enterprise and Edu, configured at workspace creation. Inference residency covers Europe (EEA + Switzerland), the US and the UAE. Search summary notes that external integrations can fall outside the region. https://openai.com/index/introducing-data-residency-in-europe/, https://help.openai.com/en/articles/9903489-data-residency-and-regional-data-processing-for-chatgpt
- Guests: someone outside the workspace who opens a shared chat link "gets no access" (search snippet). https://help.openai.com/en/articles/8798634-chatgpt-shared-links-faq-business-version. No guest or external-collaborator seat was found.

### Claude (claude.ai, Desktop, mobile, Cowork)

- Adding a server: by URL on "Free, Pro, Max, Ultra, Team, and Enterprise plans … On the Free plan, you can add one custom connector." "On Team and Enterprise plans, an Owner adds the connector for the organization, and members then connect with their own account." On Enterprise, a custom role that manages libraries can also add. https://claude.com/docs/connectors/custom/add-unlisted.md (redirect target of https://claude.com/docs/connectors/custom/remote-mcp)
- OAuth client choices: "**Use Claude's published identity** (CIMD, recommended) / **Register automatically** (DCR) / **Use your own OAuth client** (client ID; leave secret blank unless required)". Request-header static credentials are in beta. Authentication settings cannot be edited after adding. https://claude.com/docs/connectors/custom/add-unlisted.md
- CIMD selection rule: "Claude normally selects CIMD only when your authorization server metadata advertises both `"client_id_metadata_document_supported": true` and `"none"` in `token_endpoint_auth_methods_supported`, and otherwise falls back to DCR." The redirect is `https://claude.ai/api/mcp/auth_callback`. Refresh tokens should be rotated for public clients. https://claude.com/docs/connectors/building/authentication.md
- Protocol subset: "Claude follows the 2025-03-26, 2025-06-18, and 2025-11-25 authorization specifications." (2026-07-28 is not listed.) "Claude doesn't yet support these MCP features … Resource subscriptions, Sampling, Advanced or draft capabilities." Tool call timeout is 240 s. https://claude.com/docs/connectors/building/index.md
- Elicitation: absent from the building docs. The feature request "Elicitation Support" is OPEN, created 2026-04-06, 13 comments, last on 2026-10-07. https://github.com/anthropics/claude-ai-mcp/issues/153
- MCP Apps: side panel, full screen, app tools, `sendMessage`, embedded sites, file download. https://claude.com/docs/connectors/building/mcp-apps/getting-started.md. Matrix: Claude (web) supports MCP Apps and Tasks; Claude Desktop supports MCP Apps. https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/docs/extensions/client-matrix.mdx
- Enterprise Managed Auth (auto-connect without a consent screen, from IdP assertions): https://claude.com/docs/connectors/building/enterprise-managed-auth.md
- Pricing: Team Standard is $20/seat/month annual or $25 monthly, minimum 2 seats, "teams of 2 to 150". Enterprise is a $20 seat fee plus usage at API rates, minimum 20. https://claude.com/pricing
- EU: "data is stored in the US" (search snippet). https://privacy.claude.com/en/articles/7996890-where-is-my-data-stored. A US-only inference option exists on usage-based Enterprise. https://support.claude.com/en/articles/15422948-enable-us-only-inference-for-your-organization. No first-party EU residency option for claude.ai was found.
- Guests: claude.ai has no documented guest or external-member seat. Clients would need their own seats.

### Claude Tag (Claude in Slack)

- Plans: "available on Team and Enterprise plans … It isn't available on individual plans." Public beta. Channel work bills by usage to the org balance. https://claude.com/docs/claude-tag/overview.md
- Guest and Slack Connect channels: by default "Claude is disabled in any channel that includes a Slack guest". Admins can choose **Restrict / Channel only / Full access**. "Use **Channel only** to keep Claude available in a channel shared with contractors, clients, or agency partners without exposing the rest of the organization's setup." "A guest can't approve a tool or permission request … If a guest clicks approve, nothing is granted." While a guest is present, Claude does not search the workspace or publish artifacts. https://claude.com/docs/claude-tag/admins/restrict-access.md
- Custom MCP: "a plugin plus a credential". The **MCP Connector** credential means "Sign in once as an admin; the agent acts as that account". https://claude.com/docs/claude-tag/admins/connections/custom.md. Implication: in a client channel, Ploeg sees one service identity, not the client's own identity. (Inference.)
- Example workflow, "watch a bug channel … open a draft PR": https://claude.com/docs/claude-tag/users/use-cases/fix-bugs.md

The redirect is `https://teams.microsoft.com/api/platform/v1.0/oAuthRedirect`. Dynamic tool discovery is generated by default, "including any that return UI widgets (MCP apps)". Agents Toolkit ≥ 6.12.0. Page date 2026-11-16. https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/build-mcp-plugins. ## What hosted surfaces offer that Open WebUI does not (from the sources above)

- MCP Apps rendering in a host listed by the official matrix or the ext-apps "Supported Clients" list ([ext-apps README](https://github.com/modelcontextprotocol/ext-apps/blob/main/README.md)). Open WebUI and LibreChat appear in neither list. Their own feature pages were not checked in this pass.
- Elicitation that is documented for production: ChatGPT (2026-07-28 MRTR) and Copilot Cowork (form mode).
- Admin-curated org connector libraries with per-user OAuth: ChatGPT workspace apps, Claude Organization connectors, Copilot Studio, Gemini Enterprise, Perplexity, Glean.
- Distribution directories that reach clients who already pay for the host: the ChatGPT plugin directory ([submission](https://developers.openai.com/plugins/deploy/submission.md)), the Claude Connectors Directory ([publish](https://claude.com/docs/directory/publish.md)), Microsoft MCP certification ([Learn](https://learn.microsoft.com/en-us/microsoft-copilot-studio/mcp-certification)) and the Slack Marketplace.
- A governed path for clients to join a conversation: Claude Tag guest and Slack Connect channels with "Channel only" scope.
- EU residency on a hosted plan: ChatGPT Enterprise and Edu, the M365 EU Data Boundary, Mistral.
