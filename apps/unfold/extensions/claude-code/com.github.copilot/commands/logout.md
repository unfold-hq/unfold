This command runs the Unfold plugin's `scripts/unfold-login.mjs logout`. It signs the stored credential out of Unfold and removes it from this machine. VS Code gives a Copilot session no path to the plugin's scripts, so this session cannot run it.

Tell the person exactly that, in one or two sentences, and that the route is Claude Code: open Claude Code and run `/unfold:logout`.

Do not search for the script, do not run any command, and do not try to do its work another way.
