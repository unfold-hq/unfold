Approve, reject, retry or hand back a Work Item from VS Code chat, after a confirmation that names the Work Item, the effect and what it may spend.

The Unfold extension adds four chat tools for this. Declining the confirmation changes nothing, a refusal comes back in Unfold's words, and the Action Records show the action with the channel `VS Code chat`. All of the extension's chat tools are now offered only while it is signed in.
