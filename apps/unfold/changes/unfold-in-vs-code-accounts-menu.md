Unfold shows in VS Code's Accounts menu, with your account name and the workbench's host.

Signing in there runs the same browser sign-in, with the same code to compare. Signing out there does what Unfold: Sign Out does and revokes the editor credential. When the workbench stops accepting the credential, the menu shows Unfold as signed out and offers to sign in again. If you are already signed in, you stay signed in.
