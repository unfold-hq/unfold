The onboarding List picker, the readiness pull request and connecting GitLab with an Owner token now work on the Ploeg Unfold is built against.

Unfold treated these steps as not released yet and refused them with "not available yet", although the Ploeg it is built against serves them. Each onboarding step now names the first Ploeg release that ships it: the List picker 0.2.0-rc.111, the readiness pull request 0.2.0-rc.113, and the GitLab service account 0.2.0-rc.131. From 0.2.0-rc.131, GitLab also connects next to another forge. On an older Ploeg, a refused step names the release that adds it.
