Install the Unfold extension in VS Code straight from the Visual Studio Marketplace, and get updates without downloading a VSIX.

Release candidates arrive as pre-releases: choose **Switch to Pre-Release Version** on the extension's page to receive them. VS Code shows a candidate under its own version, such as `0.4.10152` for `0.4.0-rc.152`.
