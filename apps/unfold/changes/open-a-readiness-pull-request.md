Administrators can ask Ploeg for a readiness pull request that adds AGENTS.md to a repository missing only that file, from Settings → Connections.

The button shows the cap that bounds the Run and sends it as the Work Item's budget once you confirm it; a changed cap asks again. A repository gets one readiness Work Item however often the button is pressed, cancelling never starts another, and once the pull request is merged the repository shows Level 2 and is offered for a List. It turns on when the connected Ploeg serves the prepare step.
