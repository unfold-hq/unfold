After you answer, ask, leave a note or approve on the Work Item card in your AI client's chat, the model's next turn knows what you did and what came of it.

The card also offers the model tools for the Work Item it shows, such as answering its question. Each goes through the same confirmation as the matching Unfold tool, so nothing changes until you confirm. VS Code 1.147 takes the note in its chat, but offers an app's tools only in agent host sessions.
