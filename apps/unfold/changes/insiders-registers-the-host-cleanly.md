Unfold Insiders on VS Code 1.148 removes the Agents window entry it wrote to settings.json, with its token, once VS Code registers Unfold for it.

Opening a session in the Agents window finds it again for a registered host, and an editor window that VS Code connected to Unfold counts as connected in the status bar. The notice about turned-off parts now says that VS Code Stable also accepts `--enable-proposed-api`.
