The VS Code extension is now `unfold-hq.unfold-workbench`, on the Visual Studio Marketplace and Open VSX: install it, remove `unfold-hq.unfold`, and sign in again.

The old extension gets no more updates and no longer opens links from the workbench. In VS Code, release candidates arrive as pre-releases: choose **Switch to Pre-Release Version** on the extension's page to receive them.
