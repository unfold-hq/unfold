Try VS Code's experimental features with Unfold Insiders, a second build of the extension for VS Code Insiders that you install from the release's VSIX.

Run VS Code Insiders with `--enable-proposed-api unfold-hq.unfold-workbench-insiders`, disable the normal extension while it is installed, and use **Unfold Insiders: Send Feedback** to tell us what works. In Stable VS Code it behaves as the normal extension and says which parts are off.

What Unfold Insiders adds:

- What waits on you and today's spend, above the chat input, at the top of **Now**, in the status bar hover and in the chat status menu.
- Proposed work you may take on, in VS Code's Sessions list, approved with the same confirmation as in chat.
- Work Items and their pull requests linked in any chat show their state and spend, with **Approve**, **Try again** and **Hand back**.
