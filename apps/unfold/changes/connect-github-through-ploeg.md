Administrators connect GitHub and register repositories from Settings → Connections once the connected Ploeg supports it; Ploeg keeps every key.

Create the GitHub App or install the one Ploeg holds, pick the repositories the installation reaches, check each one in a dry run and register it under a key you choose. Unfold stores the repository, grants it to Own work and shows whether Ploeg can prepare it. Until Ploeg serves these steps, the checklist says which Ploeg release adds them.
