In VS Code 1.147's Agents window, a Work Item's session shows its pull request and the tracker task it came from. A pull request on GitHub also shows its checks, and the Inbox lists the session under Ready to merge or Failing CI.

Fix Checks and Address Comments on a Work Item start nothing: the reply says to steer its next Round or use Try Again, and what that may spend. Merging stays with you on the forge.
